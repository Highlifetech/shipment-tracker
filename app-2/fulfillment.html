Where everything belongs

Project cards: sales order, customer, item, ordered quantity, Hannah’s cumulative China-shipped quantity, address, and project assets.

Planned shipment storage: a dedicated SHIPMENTS - PICK PACK table in Lark. Each saved shipment contains its item snapshot, quantities per box, destination, tracking and packing summary. This is not the old SHIPMENTS demo table or the legacy shipping sheets.

Workflow after storage is enabled: Create shipment → select items → allocate box quantities → preview packing list → save as Packed → add tracking and mark Shipped. Packed reserves stock; it is not a dispatch.

Card update still to build: confirmed China dispatch should add the dispatched units to Quantity Shipped exactly once. Saving a draft, carrier delivery, and receiving in the US must not do this. US receipt must never mark a customer order fulfilled.

Photos & materials: the sandbox card now supports production photos, reference photos, designs/artwork, fabrics/swatches and material notes. Those added categories are not yet integrated into this dashboard. Packing previews can be printed to PDF; permanent PDF attachment storage is not enabled.
